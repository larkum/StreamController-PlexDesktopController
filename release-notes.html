Initial Plex Desktop Controller release.

  • Local control of the Flathub Plex Desktop app
  • Open Plex once or bring its existing window to the front, plus play/pause, stop, previous, next, seek, mute, and fullscreen actions
  • Playback controls show when Plex is not running and never launch it automatically
  • Configurable StreamController input events
  • No Plex account token or network configuration required
